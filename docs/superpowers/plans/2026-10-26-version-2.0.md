# Version 2.0: Factory Price Research Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, from scratch on branch `version-2.0`, a research tool that turns a photo or pasted requirement of hospital consumables into a cited manufacturing-cost estimate and the lowest/highest factory-direct price in India.

**Architecture:** FastAPI backend with three LangGraph graphs (intake, research, part research) separated by human steps stored in SQLite. Every number shown must trace to a quote verified against a fetched page. React frontend is an app shell (sidebar, step bar, centred content) following the approved mockup, with a calculator whose logic is shared with the backend through one JSON fixture file.

**Tech Stack:** Python 3.14 (floor 3.11), FastAPI, SQLAlchemy 2, Alembic, SQLite (WAL), LangGraph, OpenAI Python SDK (Responses API, structured output, `web_search` tool), Tavily HTTP API via httpx, Pillow. React 19, Vite, TypeScript, Tailwind 4, TanStack Query, Zustand, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-26-factory-price-research-design.md` (section 14 is the decision log; read it first). Mockup: `docs/superpowers/specs/mockups/app-v3.html`.

## Global Constraints

- Hospital consumables only. No drug or medicine feature. Medicines in the input are shown unticked with "Medicines are out of scope".
- India only, INR only. Non-INR prices are dropped, never converted.
- Factory-direct only: manufacturer sites, plus IndiaMART / TradeIndia / ExportersIndia listings whose seller is the manufacturer. Retail pharmacies and marketplaces are denylisted.
- Every price or quantity shown comes from a quote found verbatim (after normalisation) in fetched page text, or is labelled "estimate, no source".
- Range rule: confirmed manufacturers only; if none, unconfirmed sellers with label "Unconfirmed sellers only". Excluded sellers never in the range.
- Model ids come from settings `OPENAI_MODEL` and `OPENAI_VISION_MODEL`; never hard-coded.
- `backend/.env` overrides OS environment variables.
- API port 8015, web port 5173 with `--strictPort`.
- No em dashes or en dashes in code comments, UI copy, or docs.
- Results copy is short: numbers, names, links. No paragraphs.
- Defaults (all in `Settings`): budget Tavily calls 12, OpenAI web search calls 2, pages 30, LLM extraction calls 30, wall clock 180 s per item; max candidates 30; max items 10; max text 5,000 chars; page cache 24 h; research concurrency 2; broaden retries 1; overhead 10 %; mass uncertainty 15 %; unusually-low factor 0.6; outlier factor 3 (x median); offer max age 180 days.
- Split and research is a results-page action only. It never appears in the intake questions.

## Review Focus

1. **Indian price and quantity text** ("Rs. 1,25,000", "1 lakh", "₹1.80 - 2.20", "2.5 lakh pcs"): must parse to the right number. Pinned in Task 7 and Task 11.
2. **Pack price shown as a unit price** ("₹250 / Box" with no count): must be excluded from the range with flag `basis_unclear`, never divided by a guess. Pinned in Task 11.
3. **Server restart mid-research:** item must come back as `interrupted` with Retry, not stuck at `researching`. Pinned in Task 18.
4. **Answers edited after a finished run:** a new `item_run` is created and the old result remains readable. Pinned in Task 10 and Task 18.
5. **Quantity below every MOQ:** range falls back to each offer's lowest-MOQ tier with `fallback_all_moq = true`, identical in Python and TypeScript. Pinned in Task 14 and Task 28.
